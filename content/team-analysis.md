# KBO 10개 구단 전력 분석



KBO 리그 10개 구단의 주요 기록을 활용해 팀별 전력을 비교하고 분석합니다.



## 분석 목표



각 구단의 주요 경기 지표를 비교하여 팀별 강점과 약점을 파악합니다.



## 분석 항목



### 1. 타격 분석

- 팀 타율

- 출루율

- 장타율

- 홈런

- 득점



### 2. 투수 분석

- 팀 평균자책점

- WHIP

- 탈삼진

- 피안타율



### 3. 수비 분석

- 실책

- 수비율

- 팀별 수비 지표



### 4. 구단별 종합 비교

- 팀별 주요 지표 비교

- 타격과 투수력의 관계

- 팀별 전력 특징



## 사용 기술



Python, Pandas, Matplotlib



> 현재 분석 페이지는 프로젝트 계획 단계입니다. 실제 데이터를 수집하고 분석한 결과는 프로젝트 진행 후 추가할 예정입니다.
